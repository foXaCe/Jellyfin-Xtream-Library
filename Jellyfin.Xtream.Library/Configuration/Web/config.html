Métadonnées

Chaîne User-Agent personnalisée optionnelle pour les requêtes API.
Nombre de recherches de métadonnées en parallèle (1-20). Des valeurs élevées accélèrent la première synchro mais peuvent déclencher des limites de débit sur TMDb/TVDb. Par défaut : 3.
Télécharger les affiches et fanarts depuis le fournisseur pour le contenu qui n'a pas pu être identifié sur TMDb/TVDb. Garantit que les films et séries non identifiés ont quand même des illustrations dans Jellyfin.

Performance & Limitation de débit

Nombre de requêtes API en parallèle pendant la synchro (1-10). Des valeurs plus basses réduisent les erreurs de limitation de débit (429) des fournisseurs. Par défaut : 3.
Nombre de catégories à traiter par lot pendant la synchro (1-100). Des valeurs plus basses réduisent l'utilisation mémoire pour les grandes bibliothèques. Mettez 0 pour désactiver le traitement par lots. Par défaut : 10.
Délai en millisecondes entre les requêtes API (0-5000). Aide à éviter la limitation de débit (erreurs 429) des fournisseurs. Par défaut : 100ms. Mettez 0 pour aucun délai.
Nombre maximum de tentatives en cas de limitation de débit (réponse 429). Chaque tentative attend plus longtemps (backoff exponentiel). Par défaut : 3.
Délai initial après une réponse 429 avant de réessayer (100-30000ms). Chaque tentative suivante double ce délai. Par défaut : 1000ms (1 seconde).

Synchronisation incrémentale

Traiter uniquement le contenu nouveau, modifié ou supprimé après la première synchronisation complète. Réduit considérablement le temps de synchro et la charge API pour les synchronisations suivantes.
Forcer une synchronisation complète tous les N jours pour garantir la cohérence (1-30). Par défaut : 7.
Si plus de ce pourcentage de contenu a changé, basculer vers une synchro complète par mesure de sécurité (0-100%). Par défaut : 50%.

Expérimental

Récupérer les infos média (résolution, codec, audio) pendant la synchro et écrire des fichiers NFO associés. Affiche les détails média dans Jellyfin sans nécessiter une première lecture. Augmente le temps de synchro.

Dispatcharr

Découvre toutes les variantes de flux par film via l'API REST de Dispatcharr. Crée plusieurs fichiers STRM pour que Jellyfin affiche le codec, la résolution et l'audio réels dans le sélecteur de version. Nécessite un compte admin Django sur votre instance Dispatcharr.
Nom d'utilisateur admin Django pour l'API REST de Dispatcharr.
Mot de passe admin Django pour l'API REST de Dispatcharr.

Synchronisation manuelle

Éléments en échec :

Paramètres Films/VOD

Activer la synchronisation des films et du contenu VOD.

Correspondance des métadonnées

Forcer des identifiants TMDb spécifiques pour les dossiers qui ne correspondent pas automatiquement. Format : NomDuDossier=TmdbID (un par ligne). Trouvez les identifiants sur themoviedb.org.

Organisation des dossiers

Unique : Tous les films sont synchronisés dans le dossier Films racine.
Multiples : Créez des sous-dossiers et assignez des catégories à chacun.

Catégories de films

Sélectionnez les catégories à synchroniser. Laissez tout décoché pour synchroniser toutes les catégories.
Les catégories non assignées à un dossier seront synchronisées dans le dossier Films racine.

Paramètres des séries

Activer la synchronisation du contenu séries avec la structure saison/épisode.

Correspondance des métadonnées

Forcer des identifiants TVDb spécifiques pour les dossiers qui ne correspondent pas automatiquement. Format : NomDuDossier=TvdbID (un par ligne). Trouvez les identifiants sur thetvdb.com.

Organisation des dossiers

Unique : Toutes les séries sont synchronisées dans le dossier Séries racine.
Multiples : Créez des sous-dossiers et assignez des catégories à chacun.

Catégories de séries

Sélectionnez les catégories à synchroniser. Laissez tout décoché pour synchroniser toutes les catégories.
Les catégories non assignées à un dossier seront synchronisées dans le dossier Séries racine.

Paramètres TV en direct

Activer les points d'accès M3U et EPG pour le tuner TV en direct de Jellyfin.
Enregistre un type de tuner personnalisé qui évite l'analyse FFmpeg, réduisant le temps de changement de chaîne d'environ moitié. Après activation, ajoutez le tuner « Xtream Library » dans Tableau de bord → TV en direct → Tuners.
Générer les données EPG au format XMLTV pour le guide des programmes.
Format de sortie pour les flux en direct. MPEG-TS permet le streaming direct sans transcodage. Utilisez HLS uniquement si votre fournisseur ne supporte pas le TS.
Inclure les chaînes marquées comme contenu pour adultes.

Paramètres de cache

Durée de mise en cache de la playlist M3U (1-60 minutes).
Durée de mise en cache des données EPG (5-120 minutes).
Nombre de jours de données EPG à récupérer (1-7).
Nombre de requêtes EPG en parallèle (1-10). Plus élevé = plus rapide mais plus de charge sur le fournisseur.

Catégories TV en direct

Sélectionnez les catégories à inclure. Laissez tout décoché pour inclure toutes les catégories.

Nettoyage des noms de chaînes

Supprimer les préfixes de pays, tags de qualité et infos codec des noms de chaînes. Ex. : « UK: BBC One | HD | HEVC » devient « BBC One ».
Termes supplémentaires à supprimer des noms de chaînes. Un terme par ligne. Motifs intégrés : préfixes de pays (UK:, US:, etc.), tags de qualité (HD, FHD, 4K), codecs (HEVC, H.264), résolutions (1080p, 720p).

Substitutions de chaînes

Remplacer le nom, le numéro ou le logo d'une chaîne. Format : StreamId=Nom|Numéro|UrlLogo
Exemples :
123=BBC One - Renommer uniquement
456=CNN|2 - Renommer et définir le numéro de chaîne
789=Sky News|5|http://logo.png - Tous les champs
101=|10| - Numéro de chaîne uniquement (garder le nom d'origine)

Rattrapage / Timeshift

Activer les attributs de rattrapage pour les chaînes supportant le timeshift. Seules les chaînes avec tv_archive=1 chez le fournisseur supportent cette fonctionnalité.
Nombre de jours de rattrapage à afficher (1-14). Limité par la durée d'archive de la chaîne.

URLs de configuration

Ajoutez ces URLs dans les paramètres TV en direct de Jellyfin (Tableau de bord → TV en direct → Ajouter un tuner).
